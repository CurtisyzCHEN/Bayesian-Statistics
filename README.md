# About these Notes
These notes are based on the course Bayes Theory, which follows the framework of *Bayesian Statistical Methods* by Brian J. Reich & Sujit K. Ghosh. This course is designed as an advanced undergraduate or foundational postgraduate-level module. 

I attended this module at The University of Edinburgh during the 2022/23 academic year. 

Some time has passed since completing this course, yet I felt compelled to consolidate my original notes into this comprehensive reference to support the wider academic community in their learning and research.
